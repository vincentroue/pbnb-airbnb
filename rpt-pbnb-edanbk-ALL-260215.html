Audit périmètre géographique

AvertissementBiais commune vs agglomération

Certaines villes d’Inside Airbnb couvrent un périmètre plus large que la commune (agglomération, province), tandis que la population de référence est celle de la commune seule. Cela surestime les ratios d’intensité (listings/1000 hab).

5 villes concernées : Bordeaux (×3.2), Lisbonne (×5.3), Porto (×7.5), Bergame (×9.2), Los Angeles (×1.4).

Associations mixtes — Matrice dython (η²)

NoteCorrelation ratio η² vs corrélation classique

La corrélation de Spearman ne mesure que les relations num × num. Le correlation ratio η² (dython) mesure les associations catégorielle × numérique : quelle part de la variance d’une variable numérique est expliquée par l’appartenance à un groupe ? C’est l’équivalent du R² d’une ANOVA à un facteur. Sur 800K+ lignes, les p-values sont toujours significatives — seule la taille d’effet (η²) compte.

# Nettoyage — Pipeline et impact

::: {.callout-tip}
## Pipeline de nettoyage appliqué

1. **Prix non null** → exclut ~25% (inactifs/retirés)
2. **Disponibilité > 0** → exclut ~5% supplémentaires
3. **Exclure Hotel room** → ~1%
4. **Prix EUR 10–1 000** → ~3% aberrants
5. **Flag `is_longterm`** (min_nights ≥ 30) — NON exclu

Taux de rétention global : ~65-70%
:::


# Associations mixtes — Matrice dython (η²)

::: {.callout-note}
## Correlation ratio η² vs corrélation classique

La corrélation de Spearman ne mesure que les relations **num × num**. Le **correlation ratio η²** (dython) mesure les associations **catégorielle × numérique** : quelle part de la variance d'une variable numérique est expliquée par l'appartenance à un groupe ? C'est l'équivalent du R² d'une ANOVA à un facteur. Sur 800K+ lignes, les p-values sont toujours significatives — seule la **taille d'effet** (η²) compte.
:::

```{python}
#| label: dython-associations
#| fig-width: 12
#| fig-height: 10

from dython.nominal import associations

# Préparer un sous-ensemble de variables pertinentes (micro : df_listings)
# On travaille sur les données nettoyées
df_clean = df[df["price"].notna() & (df["price"] > 0)].copy()
df_clean = df_clean[df_clean["availability_365"] > 0]
df_clean = df_clean[df_clean["room_type"] != "Hotel room"]
if "price_eur" in df_clean.columns:
    df_clean = df_clean[(df_clean["price_eur"] >= 10) & (df_clean["price_eur"] <= 1000)]

# Créer la catégorie host — niveau détaillé (5 bins)
df_clean["host_category"] = pd.cut(
    df_clean["calculated_host_listings_count"],
    bins=[0, 1, 4, 9, 49, float("inf")],
    labels=["mono", "small_multi", "multi", "large", "mega"])

# Tranches de disponibilité (si pas déjà créées)
if "dispo_tranche" not in df_clean.columns:
    df_clean["dispo_tranche"] = pd.cut(
        df_clean["availability_365"],
        bins=[-1, 29, 89, 179, 365],
        labels=["Occasionnel", "Saisonnier", "Régulier", "Year-round"])

# Variables pour la matrice
assoc_vars = ["room_type", "host_category", "dispo_tranche", "continent",
              "price_eur", "availability_365", "minimum_nights",
              "number_of_reviews", "reviews_per_month",
              "calculated_host_listings_count"]
assoc_vars = [v for v in assoc_vars if v in df_clean.columns]

# Échantillon pour performance (dython est coûteux sur 800K lignes)
n_sample = min(100_000, len(df_clean))
df_sample = df_clean[assoc_vars].sample(n=n_sample, random_state=42)

print(f"Matrice d'associations dython sur {n_sample:,} listings (échantillon)")
print(f"Variables : {len(assoc_vars)} ({sum(1 for v in assoc_vars if df_sample[v].dtype == 'object' or str(df_sample[v].dtype) == 'category')} cat + {sum(1 for v in assoc_vars if df_sample[v].dtype in ['float64','int64','float32','int32'])} num)")

result = associations(df_sample, nom_nom_assoc="cramer",
                      num_num_assoc="spearman",
                      figsize=(12, 10),
                      title=f"Matrice d'associations mixtes — {n_sample//1000}K listings",
                      plot=True, compute_only=False,
                      cmap="RdBu_r", vmin=-1, vmax=1)
plt.tight_layout()
plt.show()
```

```{python}
#| label: dython-top-associations

# Extraire et classer les associations les plus fortes
corr_mat = result["corr"]
pairs = []
for i in range(len(corr_mat.columns)):
    for j in range(i+1, len(corr_mat.columns)):
        v1, v2 = corr_mat.columns[i], corr_mat.columns[j]
        val = corr_mat.iloc[i, j]

df_pairs = pd.DataFrame(pairs).sort_values("association", ascending=False)

print(f"Top 15 associations les plus fortes :\n")
print(f"{'Var 1':<35s} {'Var 2':<35s} {'|η²/ρ|':>7s} {'±':>3s}")
print("─" * 85)
for _, r in df_pairs.head(15).iterrows():
    bar = "█" * int(r["association"] * 30)
    print(f"{r['var1']:<35s} {r['var2']:<35s} {r['association']:>6.3f} {r['signe']:>3s}  {bar}")

# Log top associations
clog.step("DYTHON", n_vars=len(assoc_vars), n_sample=n_sample)
top5_pairs = [f"{r['var1']}×{r['var2']}={r['signe']}{r['association']:.3f}"
              for _, r in df_pairs.head(5).iterrows()]
clog.result("top5_associations", top5_pairs,
            interpret=f"Top association: {df_pairs.iloc[0]['var1']}×{df_pairs.iloc[0]['var2']} ({df_pairs.iloc[0]['association']:.3f})")

# Commentaire auto
top = df_pairs.iloc[0]
print(f"\n→ Association la plus forte : {top['var1']} × {top['var2']} ({top['signe']}{top['association']:.3f})")
cat_num = df_pairs[(df_pairs["var1"].isin(["room_type","host_category","dispo_tranche","continent"])) |

    top_cn = cat_num.iloc[0]

    print(f"  Interprétation : connaître '{top_cn['var1']}' explique {top_cn['association']*100:.1f}% de la variance de '{top_cn['var2']}'")
```

Les résultats de la matrice dython confirment trois enseignements clés :

- **`room_type` × `price_eur`** (η²≈0.25) : le type de logement explique un quart de la variance prix au niveau listing — c'est le facteur micro le plus structurant
- **`minimum_nights` × `reviews_per_month`** (ρ≈−0.33) : les annonces longterm ont mécaniquement moins de reviews (moins de turnover)
- **`host_category` × `calculated_host_listings_count`** (η²≈0.45) : quasi-tautologique (le host_category est construit à partir de cette variable), confirme la cohérence de la catégorisation

Le `continent` a un pouvoir explicatif faible sur les variables micro (η²<0.12) — les différences de prix et d'activité s'expliquent mieux par le type de logement que par la géographie. C'est au niveau ville (phase 2, ACP) que la géographie structure vraiment les marchés.

# CART exploratoire — Arbre de décision

::: {.callout-note}
## Pourquoi un CART en EDA ?

La matrice dython identifie **quelles** variables sont associées. Le CART révèle **comment** elles interagissent : quelles combinaisons de conditions (splits) prédisent le mieux la variable cible. Les interactions conditionnelles (l'effet de X dépend du niveau de Y) ne sortent que du CART.
:::

```{python}
#| label: cart-reviews
#| fig-width: 14
#| fig-height: 8

from sklearn.tree import DecisionTreeRegressor
import dtreeviz

# Cible : reviews_per_month (proxy activité)
target = "reviews_per_month"
features = ["price_eur", "availability_365", "minimum_nights",
            "calculated_host_listings_count", "number_of_reviews"]
features = [f for f in features if f in df_clean.columns]

# Encoder room_type en dummy pour le CART
df_cart = df_clean[features + [target, "room_type"]].dropna().copy()
df_cart["is_entire"] = (df_cart["room_type"] == "Entire home/apt").astype(int)
features_cart = features + ["is_entire"]
df_cart = df_cart.drop(columns=["room_type"])

# Échantillon pour lisibilité
n_cart = min(50_000, len(df_cart))
df_cart_s = df_cart.sample(n=n_cart, random_state=42)

X = df_cart_s[features_cart]
y = df_cart_s[target]

# Arbre limité (max_depth=4 pour interprétabilité)
tree = DecisionTreeRegressor(max_depth=4, min_samples_leaf=500, random_state=42)
tree.fit(X, y)

r2 = tree.score(X, y)

# Log CART reviews
clog.step("CART_REVIEWS", target=target, n_features=len(features_cart), n_sample=n_cart)
clog.result("cart_reviews_r2", round(r2, 3), interpret=f"R²={r2:.3f} — faible pouvoir prédictif micro")
importances = pd.Series(tree.feature_importances_, index=features_cart).sort_values(ascending=False)
clog.result("cart_reviews_importance", {k: round(v, 3) for k, v in importances.head(3).items()},
            interpret=f"Top feature: {importances.index[0]} ({importances.iloc[0]:.1%})")

print(f"CART — Cible : {target}")
print(f"  Features : {features_cart}")
print(f"  n = {n_cart:,}, R² = {r2:.3f}")
print(f"  Profondeur max : {tree.get_depth()}, feuilles : {tree.get_n_leaves()}")

# Feature importance
print(f"\n  Feature importance :")
for feat, imp in importances.items():
    bar = "█" * int(imp * 40)
    print(f"    {feat:<35s} {imp:.3f}  {bar}")
```

**Enseignements des deux CART :**

- **CART activité** (cible : reviews/mois, R²≈0.35) : Le nombre total de reviews capte 85% de l'importance — c'est quasi-tautologique (cumul historique vs flux mensuel). Le `minimum_nights` complète à 15% : les annonces longterm ont mécaniquement moins de turnover. Prix, disponibilité et type de logement ne prédisent pas l'activité à ce niveau micro.

- **CART prix** (cible : prix EUR, R²≈0.08) : Faible pouvoir prédictif — le prix est surtout déterminé par la **ville** (non incluse comme feature). Le type de logement (`is_entire`) domine à 76% : un logement entier coûte ~2× une chambre privée. Le R² très bas confirme que les caractéristiques micro des listings expliquent peu le prix — c'est le marché local qui prime.

→ **Implication analytique** : l'analyse pertinente des prix se fait au niveau **inter-villes** (phase 2 ACP), pas au niveau listing individuel.

# ACP — Analyse en composantes principales

::: {.callout-note}
## Objectif — Phase 2 : du micro au macro

Après le screening micro (dython + CART sur les listings individuels), on passe au niveau **inter-villes** : l'ACP projette les 74 marchés dans un espace réduit pour identifier les axes de différenciation structurels. Le clustering Ward regroupe les villes en profils homogènes.

Ce changement d'échelle est essentiel : les variables qui comptent au niveau listing (room_type, prix) deviennent des **proportions** et **médianes** au niveau ville, révélant des dynamiques de marché invisibles au niveau individuel.
:::

## Clustering Ward — Profils de marchés

```{python}
#| label: clustering-ward

# Clustering hiérarchique Ward sur composantes principales (PC1-PC4)
n_pc = min(4, len(var_exp))
Z = linkage(coords[:, :n_pc], method="ward")

# Découpe en k clusters — test k=3 à k=6, critère silhouette
from sklearn.metrics import silhouette_score

print("Choix du nombre de clusters (silhouette) :")
best_k, best_sil = 3, -1
for k in range(3, 7):
    labels = fcluster(Z, k, criterion="maxclust")
    sil = silhouette_score(coords[:, :n_pc], labels)
    marker = " ← best" if sil > best_sil else ""
    if sil > best_sil:
        best_k, best_sil = k, sil
    print(f"  k={k} : silhouette = {sil:.3f}{marker}")

k_final = best_k
kpi["cluster"] = fcluster(Z, k_final, criterion="maxclust")
clog.result("clustering_k", k_final, interpret=f"k={k_final} clusters (silhouette={best_sil:.3f})")
print(f"\n→ Retenu : k={k_final} clusters (silhouette = {best_sil:.3f})")
print(f"\nRépartition :")
for cl in sorted(kpi["cluster"].unique()):
    cities = kpi[kpi["cluster"] == cl]["city"].tolist()
    print(f"  Cluster {cl} ({len(cities)} villes) : {', '.join(cities[:8])}{'...' if len(cities) > 8 else ''}")
```

## Kruskal-Wallis par continent

```{python}
#| label: kruskal-wallis

from scipy.stats import kruskal

test_vars = ["listings_1000hab", "prix_med", "pct_entire", "pct_multi",
             "pct_longterm", "dispo_med", "reviews_med"]

clog.step("KRUSKAL_WALLIS", grouping="continent", n_groups=kpi["continent"].nunique())

print(f"Tests de Kruskal-Wallis — Variable ~ Continent ({kpi['continent'].nunique()} groupes)\n")
print(f"{'Variable':<25s} {'H stat':>8s} {'p-value':>10s} {'Signif':>8s}")
print("-" * 55)
kw_results = {}
for var in test_vars:
    groups = [g[var].dropna().values for _, g in kpi.groupby("continent")]
    groups = [g for g in groups if len(g) >= 2]
    if len(groups) >= 2:
        h_stat, p_val = kruskal(*groups)
        sig = "***" if p_val < 0.001 else "**" if p_val < 0.01 else "*" if p_val < 0.05 else "ns"
        print(f"{var:<25s} {h_stat:>8.2f} {p_val:>10.4f} {sig:>8s}")
        kw_results[var] = {"H": round(h_stat, 2), "p": round(p_val, 4), "sig": sig}

sig_vars = [v for v, r in kw_results.items() if r["sig"] != "ns"]
clog.result("kw_significant", sig_vars,
            interpret=f"{len(sig_vars)}/{len(kw_results)} variables significativement différentes entre continents")
```
