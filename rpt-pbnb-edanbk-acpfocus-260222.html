AstuceComment lire la matrice de corrélation
  • Bleu foncé = corrélation positive forte (les deux variables augmentent ensemble)
  • Rouge foncé = corrélation négative forte (quand l’une augmente, l’autre diminue)
  • Blanc = pas de lien linéaire entre les variables
  • Les corrélations fortes (|r| > 0.5) indiquent des redondances potentielles dans l’ACP — deux variables qui mesurent presque la même chose. L’ACP les synthétisera en un axe commun.
  • Les corrélations faibles (|r| < 0.3) signifient que les variables apportent une information complémentaire — bon signe pour la diversité du jeu de variables.

AstuceComment lire le screeplot
  • Chaque barre = part de variance expliquée par une composante principale (axe)
  • La courbe orange = variance cumulée — on cherche le coude où elle atteint ~80%

AstuceComment lire les loadings
  • Un loading mesure la corrélation entre une variable et un axe factoriel (entre -1 et +1)
  • Loading élevé (+0.4 à +1) : la variable contribue fortement dans le sens positif de l’axe
  • Loading négatif (-1 à -0.4) : la variable contribue dans le sens opposé
  • Loading faible (-0.3 à +0.3) : la variable est mal représentée sur cet axe — regarder les axes suivants
  • Les variables avec des loadings opposés sur un même axe forment un gradient (ex : prix élevé ↔︎ pression forte)
  • L’interprétation des axes se fait en nommant le gradient : “axe prix-qualité”, “axe pression-régulation”, etc.

AstuceComment lire les profils de cluster
  • Chaque ligne = un cluster identifié par le Ward. Les valeurs sont les médianes des variables ACP pour les villes du cluster.
  • Comparer les colonnes : une valeur nettement au-dessus/dessous de la médiane globale caractérise le profil.

  • Les clusters mono-ville ou très petits (n=2) sont souvent des outliers — les interpréter avec prudence.

AstuceComment lire les tests de Kruskal-Wallis
  • Kruskal-Wallis = test non paramétrique qui compare les distributions d’une variable entre k groupes (continents ou clusters)
  • H stat = statistique du test. Plus elle est élevée, plus les groupes diffèrent sur cette variable
  • p-value = probabilité d’observer cette différence par hasard. Seuils : *** < 0.001, ** < 0.01, * < 0.05
  • ns (non significatif) = les groupes ne diffèrent pas significativement sur cette variable
  • Variables significatives entre continents → la géographie structure le marché Airbnb sur cette dimension
  • Variables significatives entre clusters → la variable contribue effectivement à la différenciation des profils (cohérence ACP↔︎clustering)
  • Attention : avec k > 2 groupes, KW dit “il y a une différence” mais pas entre quels groupes. Pour ça il faudrait un test post-hoc (Dunn).

CART — Seuils discriminants (Monde)

NotePourquoi un arbre de décision après le clustering ?

Le clustering (Ward) identifie quels groupes existent. L’arbre de décision (CART) explique pourquoi une ville appartient à tel groupe : il identifie les seuils de coupure sur les variables les plus discriminantes. C’est la version interprétable et explicable des profils.

Lecture : à chaque nœud, l’arbre teste une condition (ex : “pression > 12 ?”). Les branches gauche/droite mènent à des sous-groupes de plus en plus homogènes. Les feuilles indiquent le profil prédit.

AstuceComment lire l’arbre CART
  • Chaque nœud contient : la condition de split, le nombre d’échantillons (villes), et la distribution entre les classes (profils)
  • Gini = mesure d’impureté (0 = pur, 0.5 = mélange maximal). L’arbre cherche à minimiser le Gini à chaque split.
  • Les couleurs correspondent aux profils majoritaires dans chaque nœud
  • L’importance Gini d’une variable = contribution totale de cette variable à la réduction d’impureté dans l’arbre. Variable importante = très discriminante pour séparer les profils.
  • Lire le chemin : suivre une ville depuis la racine jusqu’à la feuille donne les conditions qui définissent son profil
  • Limites : l’arbre est ajusté sur les mêmes données que le clustering (pas de validation croisée) — l’accuracy est indicative, pas une mesure de généralisation

NoteMéthodologie

Variables actives : 10 indicateurs centrés-réduits (z-scores) couvrant 5 dimensions : pression, prix, structure, concentration, satisfaction.

ACP : décomposition en valeurs propres de la matrice de corrélation (sklearn PCA + FactoMineR).

Clustering : Ward sur les 4 premières composantes principales. Choix de k par score silhouette (k ∈ {3..6}).

Pourquoi Ward sur composantes ? Les variables ont des échelles très différentes (pression 0–55, prix 37–300, pourcentages 0–98). L’ACP apporte décorrélation (distance euclidienne cohérente), réduction de bruit (composantes mineures exclues) et interprétabilité (clusters lisibles sur le biplot).

Sources : Inside Airbnb (sumlistings + listings.gz, juin 2025), populations ville-centre (recensements nationaux), taux de change BCE février 2026.

Limites : snapshot unique (pas de temporalité), périmètre géographique variable entre villes, populations parfois estimées.

## Comment lire la matrice de corrélation

- **Bleu foncé** = corrélation positive forte (les deux variables augmentent ensemble)
- **Rouge foncé** = corrélation négative forte (quand l'une augmente, l'autre diminue)
- **Blanc** = pas de lien linéaire entre les variables
- Les corrélations fortes (|r| > 0.5) indiquent des **redondances potentielles** dans l'ACP — deux variables qui mesurent presque la même chose. L'ACP les synthétisera en un axe commun.
- Les corrélations faibles (|r| < 0.3) signifient que les variables apportent une **information complémentaire** — bon signe pour la diversité du jeu de variables.
:::

```{python}
#| label: monde-corr-insights

pairs_seen = set()
```

## Comment lire le screeplot

- Chaque **barre** = part de variance expliquée par une composante principale (axe)
- La **courbe orange** = variance cumulée — on cherche le coude où elle atteint ~80%
- **PC1** capture la dimension la plus structurante du jeu de données (souvent le gradient prix/pression)
- **PC2** capture la 2ᵉ dimension indépendante (souvent structure/professionnalisation)
- **Règle du coude** : on retient les composantes avant que la courbe ne s'aplatisse (rendements décroissants)
- Si PC1+PC2 > 50% : le biplot 2D est une bonne représentation ; si < 40% : les axes suivants comptent aussi

## Comment lire les loadings

- Un **loading** mesure la corrélation entre une variable et un axe factoriel (entre -1 et +1)
- **Loading élevé** (+0.4 à +1) : la variable contribue fortement dans le sens positif de l'axe
- **Loading négatif** (-1 à -0.4) : la variable contribue dans le sens opposé
- **Loading faible** (-0.3 à +0.3) : la variable est mal représentée sur cet axe — regarder les axes suivants
- Les variables avec des loadings opposés sur un même axe forment un **gradient** (ex : prix élevé ↔ pression forte)
- L'interprétation des axes se fait en nommant le gradient : "axe prix-qualité", "axe pression-régulation", etc.

```{python}
#| label: monde-clustering-ward

from sklearn.metrics import silhouette_score

# Clustering Ward sur composantes principales
n_pc = min(4, len(var_exp))
Z_monde = linkage(coords_monde[:, :n_pc], method="ward")

print("Choix du nombre de clusters (silhouette) — Monde :")
best_k, best_sil = 3, -1
for k in range(3, 7):
    labels = fcluster(Z_monde, k, criterion="maxclust")
    sil = silhouette_score(coords_monde[:, :n_pc], labels)
    marker = " ← best" if sil > best_sil else ""
    if sil > best_sil:
        best_k, best_sil = k, sil
    print(f"  k={k} : silhouette = {sil:.3f}{marker}")

k_monde = best_k
kpi_monde["cluster"] = fcluster(Z_monde, k_monde, criterion="maxclust")
clog.result("monde_clustering_k", k_monde,
            interpret=f"k={k_monde} clusters (silhouette={best_sil:.3f})")
print(f"\n→ Retenu : k={k_monde} clusters (silhouette = {best_sil:.3f})")
print(f"\nRépartition :")
for cl in sorted(kpi_monde["cluster"].unique()):
```

- Chaque ligne = un cluster identifié par le Ward. Les valeurs sont les **médianes** des variables ACP pour les villes du cluster.
- Comparer les colonnes : une valeur nettement au-dessus/dessous de la médiane globale caractérise le profil.
- Le **score silhouette** mesure la qualité de la partition (0 à 1). Au-dessus de 0.3 = structure raisonnable, >0.5 = bonne.
- **Nommer les profils** : identifier 2-3 traits dominants par cluster (ex : "pression touristique forte + prix modéré" → profil "tourisme de masse").
- Les clusters mono-ville ou très petits (n=2) sont souvent des **outliers** — les interpréter avec prudence.
:::

## Comment lire le dendrogramme

- L'axe vertical = **distance d'agrégation** (Ward). Plus la barre de fusion est haute, plus les groupes fusionnés étaient différents.
- La **ligne rouge** horizontale = coupe retenue pour former k clusters. Les branches en dessous forment les groupes.

# Tests statistiques — Monde

## Kruskal-Wallis par continent

```{python}
#| label: monde-kruskal-wallis
#| results: hold

from scipy.stats import kruskal

test_vars = ACP_VARS.copy()

clog.step("KRUSKAL_WALLIS_MONDE", grouping="continent",
          n_groups=kpi_monde["continent"].nunique())

print(f"Tests de Kruskal-Wallis — Variable ~ Continent ({kpi_monde['continent'].nunique()} groupes)\n")
print(f"{'Variable':<25s} {'H stat':>8s} {'p-value':>10s} {'Signif':>8s}")
print("-" * 55)
kw_results_monde = {}
for var in test_vars:
    groups = [g[var].dropna().values for _, g in kpi_monde.groupby("continent")]
    groups = [g for g in groups if len(g) >= 2]
    if len(groups) >= 2:
        h_stat, p_val = kruskal(*groups)
        sig = "***" if p_val < 0.001 else "**" if p_val < 0.01 else "*" if p_val < 0.05 else "ns"
        print(f"{var:<25s} {h_stat:>8.2f} {p_val:>10.4f} {sig:>8s}")
        kw_results_monde[var] = {"H": round(h_stat, 2), "p": round(p_val, 4), "sig": sig}

sig_vars = [v for v, r in kw_results_monde.items() if r["sig"] != "ns"]
clog.result("kw_monde_significant", sig_vars,
            interpret=f"{len(sig_vars)}/{len(kw_results_monde)} variables significativement différentes entre continents")
```

::: {.callout-tip collapse="true"}
## Comment lire les tests de Kruskal-Wallis

- **Kruskal-Wallis** = test non paramétrique qui compare les distributions d'une variable entre k groupes (continents ou clusters)
- **H stat** = statistique du test. Plus elle est élevée, plus les groupes diffèrent sur cette variable
- **p-value** = probabilité d'observer cette différence par hasard. Seuils : *** < 0.001, ** < 0.01, * < 0.05
- **ns** (non significatif) = les groupes ne diffèrent pas significativement sur cette variable
- Variables significatives entre **continents** → la géographie structure le marché Airbnb sur cette dimension
- Variables significatives entre **clusters** → la variable contribue effectivement à la différenciation des profils (cohérence ACP↔clustering)
- **Attention** : avec k > 2 groupes, KW dit "il y a une différence" mais pas *entre quels groupes*. Pour ça il faudrait un test post-hoc (Dunn).
:::

## CART — Seuils discriminants (Monde)

::: {.callout-note}
## Pourquoi un arbre de décision après le clustering ?

Le clustering (Ward) identifie **quels groupes** existent. L'arbre de décision (CART) explique **pourquoi** une ville appartient à tel groupe : il identifie les **seuils de coupure** sur les variables les plus discriminantes. C'est la version interprétable et explicable des profils.

**Lecture** : à chaque nœud, l'arbre teste une condition (ex : "pression > 12 ?"). Les branches gauche/droite mènent à des sous-groupes de plus en plus homogènes. Les feuilles indiquent le profil prédit.
:::

::: {.callout-tip collapse="true"}
## Comment lire l'arbre CART

- Chaque **nœud** contient : la condition de split, le nombre d'échantillons (villes), et la distribution entre les classes (profils)
- **Gini** = mesure d'impureté (0 = pur, 0.5 = mélange maximal). L'arbre cherche à minimiser le Gini à chaque split.
- Les **couleurs** correspondent aux profils majoritaires dans chaque nœud
- L'**importance Gini** d'une variable = contribution totale de cette variable à la réduction d'impureté dans l'arbre. Variable importante = très discriminante pour séparer les profils.
- **Lire le chemin** : suivre une ville depuis la racine jusqu'à la feuille donne les conditions qui définissent son profil
- **Limites** : l'arbre est ajusté sur les mêmes données que le clustering (pas de validation croisée) — l'accuracy est indicative, pas une mesure de généralisation
:::

::: {.callout-note collapse="true"}
## Méthodologie

**Variables actives** : 10 indicateurs centrés-réduits (z-scores) couvrant 5 dimensions : pression, prix, structure, concentration, satisfaction.

**ACP** : décomposition en valeurs propres de la matrice de corrélation (sklearn PCA + FactoMineR).

**Clustering** : Ward sur les 4 premières composantes principales. Choix de k par score silhouette (k ∈ {3..6}).

**Pourquoi Ward sur composantes ?** Les variables ont des échelles très différentes (pression 0–55, prix 37–300, pourcentages 0–98). L'ACP apporte décorrélation (distance euclidienne cohérente), réduction de bruit (composantes mineures exclues) et interprétabilité (clusters lisibles sur le biplot).

**Sources** : Inside Airbnb (sumlistings + listings.gz, juin 2025), populations ville-centre (recensements nationaux), taux de change BCE février 2026.

**Limites** : snapshot unique (pas de temporalité), périmètre géographique variable entre villes, populations parfois estimées.
